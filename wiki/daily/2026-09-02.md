# 2026-09-02

## Code and wiki review

Full pass across the code and the wiki, ahead of a promotion push.

**Three verified bugs:**

- Perception Report arc minutes ignore the active media's crop and the
  device's fit mode — a verdict can be computed against the wrong
  region of the wrong effective size.
- The setup assistant overwrites This Device with a stale mount-time
  draft, clobbering any edit made mid-flow.
- Pointer gestures (drag/resize handles) have no cancel path — nothing
  releases the drag if the pointer leaves the window or another input
  interrupts it.

**Medium issues, worth a pass but not urgent:**

- An `Infinity` verdict paints green instead of flagging as broken.
- A side effect lives inside a state updater (should be a plain
  action).
- IndexedDB writes re-read the full media library on every write
  instead of touching just the changed record.
- Setup import validation is loose — a malformed file can partially
  apply.
- Some import failures fail silently with no user-visible error.
- `devicePixelRatio` is captured once and goes stale if the window
  moves screens or the OS scale changes mid-session.
- An object URL gets revoked before its last consumer is done with it.
- A few texture and cursor-listener leaks on unmount.
- The ISO band-color function is copied four times across components;
  the 2D scale formula is copied three times.

**Docs drift** (this pass): the PRD described the April 2025 sketch,
not the shipped app; the 2026-08-15 open-questions note sat open with
all three questions long resolved; CLAUDE.md's lib-purity rule claimed
none of `lib/` touches the DOM when several files do.

**Process gaps:** no CI running on `dev` yet, the Bun pin has drifted
from what CI (once it exists) will assume, and `package.json` is still
at `0.1.0` despite seven tags shipped.

Fixes for the verified/medium issues run on `feature/review-fixes`;
the CI and Bun-pin work runs on `feature/ci-and-bun` — both separate
worktrees, not this pass. Filed GitHub issues for keyboard
accessibility (2D selection, measure boxes, panel move/resize) and for
review of this PRD rewrite.

- created [[plans]] — MOC indexing every plan-*, report-*, review-*,
  and prototype-* note, since two of them (the pro-polish plan and its
  overnight report) were reachable only from a daily note.
