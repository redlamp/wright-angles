# Fonts

- `barlow-latin-500-normal.woff` — Barlow Medium (latin subset), copied from
  `@fontsource/barlow@5.3.0` (`files/barlow-latin-500-normal.woff`). Used by
  the 3D view's troika/drei `<Text>` labels, which need a `.ttf`/`.otf`/`.woff`
  file URL (troika does not parse `.woff2`, and CSS `@fontsource` faces are
  invisible to WebGL text). Barlow is licensed under the SIL Open Font
  License 1.1 (OFL-1.1); © Jeremy Tribby, https://tribby.com/fonts/barlow/.
